\title{Writings that are not statements}
\begin{document}
\maketitle
An ambiguous writing, a brace left open, an unknown command, an item with
words only. Each must be refused with a reason, never read one way or the
other.
\begin{enumerate}
\item $\displaystyle \frac{d}{dx}(x^{2}) \cdot (x) = 3x^{2}$
\item $\displaystyle \frac{1}{x = 2$
\item $\displaystyle \thiscommanddoesnotexist{x} = x$
\item This item has no formula.
\end{enumerate}
